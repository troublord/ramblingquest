終於完成 iThome 鐵人賽了，九月我紮紮實實連續寫了三十篇文章，真是太恐怖了

在過程中我甚至一度懷疑這種高強度的賽程，還參加第二次的我是不是有受虐傾向。

回頭評估一下，我還真的有受虐傾向。

因為我一寫完，馬上又開始找「下個要投身的項目是什麼」。要知道

本質上這種連續三十天寫出一篇文章的賽程，是沒有任何實質收益的。大神雖然收穫流量，但大神本來就有名聲；小白想要鍛鍊技術，但三十天份的文章光是趕稿就應接不暇。

像我這種卡在中間的軟體工程師，往往會發現參賽既得不了名、練了技術也不知道要幹嘛，因為 AI 時代，高機率練了也馬上被迭代掉。

那我幹嘛還參賽呢，這個問題……也許是一種信念吧，我相信這趟冒險的收穫，多過眼前能獲得的利益。

而實際上我的收穫確實換不到錢，也換不太到名聲（很難說有多少人是不小心點進來的）

我的收穫它是一種理解、一種使用 AI 的智慧，讓我展開說說：

我做了一個簡單的「文章潤稿自動化」的 Skill，現在一篇文章寫完，我只要打 /hoard-polish ，AI 就知道我在寫文章，並且要潤稿了，它會自動檢查行文、邏輯、錯字、標點符號、排版、贅字贅詞、名詞統一。

都是我在寫三十篇文章的過程中遇到的問題，現在打一串 /hoard-polish 就解決了。

還有每篇文章的標題建議，過往寫得盡興之後會發現整篇內文沒有小標題去引導讀者，文章的大標題也不知道要取啥，現在打一串 /hoard-title AI 就知道我想要討論標題，就根據合理性、流量、達意等方面給我建議，最後可以直接給我幾個候選方向讓我選。

簡單的兩行指令，省了我大量的時間。

除了這兩行之外，還有這麼多

![Obsidian 知識庫的資料夾結構，topics 底下有心理、職涯、AI 輔助開發、LLM Wiki、writing 等主題](/images/wiki-topics-folder.webp)

這都是沒有實質回報的知識整理，看起來只是一坨資料夾搭配一大堆的文檔。

但是這些文檔將會為我解決各種我人生中遇到的關卡，跟 AI 一起。

所以回答我自己在前面的問題，我為什麼要參賽，為什麼要自虐？

因為鑽研一個看似沒用的主題，比起做你已經會的事情並且以此獲利，能賺得更多智慧

畢竟撞到更多牆嘛，所以我 IG 的自介才說我是「南牆衝撞者」哈。

## 強大的「沒用」主題

那麼我具體鑽研了什麼沒用的主題呢，其實它比想像中強大哦（聽過「第二大腦」嗎？）

LLM Wiki，雖然在今年四月風靡一時，但實際流量還是蠻低的，不過流量低不代表沒用。

我做了一個給 [Claude Code](https://claude.com/claude-code) 使用的個人知識庫模板，所有有訂閱 Claude Code 的人都能直接取用並且自己開始建「個人知識庫」

你不需要知道 LLM Wiki 在幹嘛，不需要學習各種 AI 知識，甚至你不用知道 Git 是什麼。

你只需要有訂閱 Claude Code ，願意用 Obsidian 來做筆記、存檔案，最後懂得問 AI

repo 裡有附取用教學：
[itwilldo-wiki-demo](https://github.com/troublord/itwilldo-wiki-demo)

![GitHub 上 itwilldo-wiki-demo 的 README，說明這是給 Claude Code 使用的個人知識庫骨架](/images/itwilldo-wiki-readme.webp)

真的還是不會，直接問 AI 就好。

在 AI 時代，如果你對於落後感到焦慮、學習難以複用感到厭煩，那麼推薦你用用看這個模板。
